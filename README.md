# 📊 Netflix Data Analysis

## 📌 Project Overview
This project focuses on analyzing the Netflix dataset to uncover insights about content distribution, genres, and trends. The analysis is performed using Python libraries.

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib

---

## 🔍 Key Analysis Performed
- 📺 Movies vs TV Shows comparison  
- 🌍 Top 5 countries with most content  
- 🎭 Genre distribution analysis  
- 🧹 Data cleaning (handling null values & preprocessing)

---

## 📊 Key Insights
- Majority of content on Netflix is Movies  
- USA has the highest number of shows  
- Drama and Comedy are the most popular genres  

---

## 📁 Dataset
- Netflix dataset (Kaggle)

---

## 🚀 How to Run
1. Download the dataset  
2. Open the project file (`project-1.py`)  
3. Run using Python
